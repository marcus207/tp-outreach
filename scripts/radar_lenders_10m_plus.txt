# Maturity radar: LENDER CATEGORIES (feeds the likely-loan-size score; NOT a filter any more)
#
# Used by scripts/radar_size.py. Since 6 Oct 2026 this is no longer a pass/fail allowlist: clearing
# banks lend at every size, so being on a list did not establish a GBP 10m+ loan. Each lender is now
# put in a CATEGORY, and the category's weight lives in scripts/radar_size_rules.json
# ("lender_categories"): large-ticket categories add a medium-strong size signal; clearing banks,
# UK challengers and small-ticket specialists add nothing. A lender in no category also adds nothing
# (it is still scored on the other signals). BTL / residential lenders and housebuilder counterparties
# remain HARD EXCLUDES in scripts/maturity_radar.py (BTL_LENDERS, HOUSEBUILDERS).
#
# Format:
#   - [section] lines start a category (must match a key in radar_size_rules.json lender_categories)
#   - one case-insensitive Python regex per line (plain names work as-is)
#   - '#' starts a comment (whole line, or after whitespace at the end of a line)
#   - '# CHECK' marks a placement we are unsure about (informational; shown in the lender review CSV)
# If a lender matches several sections, the strongest category wins.
# Data-driven helper for additions: reports/radar/lender-review-YYYY-MM-DD.csv
